What this demonstration verifies—and where it stops

This public page calls the same pure PHP engine included in the WordPress plugin. Each request analyses a fixed fictional scenario. The public endpoint accepts no arbitrary payload, URL, credentials or real order information; it stores no review state.

Exact replay checks use an explicitly supplied prior ledger. The engine’s sequence watermark records observed admissible events; it does not prove an order was applied. The plugin’s WordPress/WooCommerce verification and release evidence are documented separately in the repository. No production qualification or WordPress.org directory approval is claimed.
