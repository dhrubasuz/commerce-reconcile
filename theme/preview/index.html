04 / Craft notes

A store,
carefully composed.

A working design preview of the installable classic theme. The WordPress and WooCommerce runtime are separate from this static page.

01

An original identity

Cream, forest and terracotta. A geometric mark, editorial type and original vector illustrations form one visual system. System fonts and local assets keep it self-contained.

02

Designed for the screen

The catalogue moves from three columns to two, then one. Native product disclosures, visible focus states, a skip link and reduced-motion support make the small interactions deliberate.

03

Built for WordPress

The classic theme supports custom logos, navigation menus, page content and an optional WooCommerce catalogue. Dynamic product text, URLs and permitted HTML have distinct escaping paths.

i

You are viewing the static design preview.Category filters and native detail disclosures work in this page. It does not run PHP, WordPress, WooCommerce, cart, checkout or payment processing. The repository contains the separate installable theme and integration instructions.
